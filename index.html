Редактирование выезда
Условия

Записи хранятся на телефоне. Дома отправь их на Mac во вкладке «Выезды».

Справочник

Если «Вставить из буфера» не сработало, вставь текст сюда вручную:

Как пользоваться

  1. На Mac: приложение → «Добавить улов» → вкладка «Данные» → «📱 Телефон». Два способа передать справочник:
    а) через буфер: нажми «📋 Скопировать справочник» на Mac, а здесь «Вставить из буфера» (нужен один Apple ID и Wi-Fi/Bluetooth на обоих устройствах);
    б) файлом: «⬇ Справочник для телефона» → AirDrop на iPhone → «Сохранить в Файлы» → здесь «Выбрать файл справочника».
  2. Делай это в приложении со значка на экране «Домой», а не во вкладке Safari.
  3. На берегу: вкладка «Запись». Интернет не нужен.
  4. Дома: «Выезды» → «Отправить на Mac» → AirDrop. На Mac: «Данные» → «Записи с телефона».
  5. После загрузки на Mac нажми «Загрузил — убрать отправленные».
