КОД СПИННИНГИСТА — страница для iPhone (запись уловов на берегу без интернета)

ЧТО ЭТО
Лёгкое приложение для телефона. Один раз открываешь его с интернетом — дальше оно работает
без сети. Записи хранятся на самом телефоне, пока ты не отправишь их на Mac.
Никакие твои данные в интернет не попадают: на GitHub лежит только «пустая форма».

══════════════════════════════════════════
 ШАГ 1. Положить страницу на GitHub Pages (один раз, бесплатно, ~5 минут)
══════════════════════════════════════════
1. Распакуй Rybalka-phone.zip на Mac (получится папка с файлами).
2. Зайди на github.com под своим аккаунтом. Справа вверху «+» → «New repository».
3. Repository name: rybalka-phone   ·   Public (публичный)   ·   нажми «Create repository».
4. В новом репозитории найди ссылку «uploading an existing file» (или кнопка «Add file» →
   «Upload files»). Перетащи в окно браузера ВСЕ файлы из распакованной папки (сами файлы,
   не папку целиком). Дождись, пока они появятся в списке, и нажми зелёную «Commit changes».
5. Вверху репозитория «Settings» → слева «Pages». В блоке «Build and deployment»:
   Source — «Deploy from a branch»; Branch — «main» и папка «/ (root)» → «Save».
6. Подожди 1–3 минуты, обнови страницу Settings → Pages. Появится строка
   «Your site is live at https://…github.io/rybalka-phone/». Это адрес твоей страницы
   (обычно https://spinningista.github.io/rybalka-phone/ — но проверь именно по строке).

══════════════════════════════════════════
 ШАГ 2. Поставить на iPhone (один раз)
══════════════════════════════════════════
1. Открой этот адрес в Safari (именно в Safari, не внутри Telegram и т.п.). Нужен интернет.
   Если github.io не открывается без VPN — включи VPN только на этот раз.
2. Подожди, пока страница загрузится. Нажми «Поделиться» (квадрат со стрелкой) →
   «На экран «Домой»» → «Добавить».
3. Дальше запускай приложение только с иконки на экране «Домой» — оно работает без интернета.

══════════════════════════════════════════
 ШАГ 3. Справочник на телефон
══════════════════════════════════════════
1. На Mac: приложение → «➕ Добавить улов» → вкладка «Данные» → «📱 Телефон» →
   «⬇ Справочник для телефона». Получишь файл rybalka_catalog.json.
2. Отправь его на iPhone по AirDrop; на iPhone выбери «Сохранить в Файлы».
3. В приложении на телефоне: «Ещё» → «Загрузить файл справочника» → выбери файл.
   Справочник стоит обновлять после того, как на Mac появились новые водоёмы, приманки, места.

══════════════════════════════════════════
 КАЖДАЯ РЫБАЛКА
══════════════════════════════════════════
• На берегу: вкладка «Запись» — дата, условия, водоём, место, приманка, рыба, количество,
  вес, фото. Можно несколько уловов за выезд. «Сохранить выезд». Интернет не нужен.
• Дома: вкладка «Выезды» → «📤 Отправить на Mac» → AirDrop → свой Mac.
• На Mac: приложение → «Данные» → «Записи с телефона» → выбери файл (он в «Загрузках») →
  проверь → «Загрузить в журнал».
• Потом на телефоне нажми «✅ Загрузил на Mac — убрать отправленные».
Если файл по какой-то причине загрузили дважды — дублей не будет.

ВАЖНО
• Иконку на экран «Домой» добавь обязательно: без неё iPhone может стереть данные сайта,
  если им долго не пользоваться. Записи старайся отправлять на Mac в тот же день.
• Обновить саму страницу позже: загрузи новые файлы в тот же репозиторий (с заменой);
  телефон подхватит их при следующем открытии с интернетом.
